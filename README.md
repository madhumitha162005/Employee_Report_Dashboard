👥 Employee Report Dashboard
📊 Project Overview

The Employee Report Dashboard is an interactive Power BI dashboard designed to analyze employee information and workforce performance. It provides insights into employee distribution across departments and cities, salary patterns, and performance ratings.

🎯 Objectives
Analyze employee distribution by department.
Understand salary patterns across departments.
Analyze employee performance ratings.
Explore employee distribution by city.
Provide an interactive view of workforce information.
Support HR teams in understanding employee data.
🛠️ Tools & Technologies
Power BI Desktop

DAX
Data Visualization
Excel / Structured Dataset
📌 Key Features
Interactive KPI cards
Department-wise employee analysis
Salary analysis
Performance rating analysis
City-wise employee distribution
Department and city slicers
Interactive Power BI visuals
Map-based employee distribution
📈 Dashboard KPIs

The dashboard provides key metrics such as:

Total Employees
Total Salary
Department Summary
Performance Rating
Employee Distribution
📊 Dashboard Analysis
Department Analysis

Visualizes the number of employees across different departments to understand workforce distribution.

Salary Analysis

Analyzes salary information across departments and helps identify salary patterns.

Performance Analysis

Provides department-wise performance rating insights to understand employee performance.

Location Analysis

Uses city-level information to visualize employee distribution across different locations.

Interactive Filtering

Users can filter the dashboard using City and Department slicers to explore specific employee groups.
